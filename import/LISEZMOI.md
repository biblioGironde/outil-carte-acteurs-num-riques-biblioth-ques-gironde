# Dossier d'import

Déposez ici un fichier `.csv` construit sur le modèle [`docs/modele-import.csv`](../docs/modele-import.csv)
(*Add file → Upload files*). Une action le lit automatiquement, géolocalise chaque structure et ouvre une
proposition de modification (pull request) avec le rapport : acteurs ajoutés, lignes refusées et pourquoi.

Le fichier est retiré du dossier une fois traité. Rien n'apparaît sur la carte avant validation.
